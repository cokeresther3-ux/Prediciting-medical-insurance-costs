# Prediciting-medical-insurance-costs

Machine learning techniques were performed on the insurance dataset that contains qualitative and quantitative data. The dataset contained three numerical features namely age, BMI and children, and categorical features namely sex, smoker and region. A regression model was used to predict a continuous numerical outcome and to identify how the independent variables (Age, BMI and smoker) affect the dependent variable (charges). Preprocessing of the data using feature engineering was performed through converting categorical variables into numerical values using one-hot encoding, which converts categorical variables into distinct binary indicator variables. Furthermore, the dataset did not contain any missing values, thus imputation was not performed. The dataset was then divided into a training set (80%) and a test set (20%), sampled at random. The training dataset was used to build a model that predicts the insurance costs while the test dataset was used to evaluate the performance of the regression model on unseen data. The analysis was performed using Python and libraries such as NumPy and Pandas for data manipulation, Seaborn and Matplotlib for data visualisation and Scikit-learn for machine learning modelling. The LinearRegression class from scikit-learn library was used to implement the regression model. The performance and accuracy of the model was evaluated using the mean absolute error (MAE), mean squared error (MSE), root mean squared error (RMSE) and the R² score. To explore relationships between variables, a correlation matrix was computed to determine which features are the most important for determining insurance. A heatmap was used to visualise the relationships.
